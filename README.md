# Emotion Detector

## Project Description

An AI-based Emotion Detector application developed using Python, Watson NLP, and Flask.

The application analyzes text and detects emotions such as:
- Anger
- Disgust
- Fear
- Joy
- Sadness

## Technologies Used

- Python
- Watson NLP
- Flask
- Unit Testing
- Pylint
